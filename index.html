Ayarlar

Anahtar nasıl alınır
  1. GitHub'da yeni fine-grained token sayfasını aç.
  2. Token name: cihazın adı (ör. Düzen ThinkPad). Expiration: No expiration ya da uzun bir süre.
  3. Repository access: Only select repositories, sonra Select repositories'den duzen-veri.
  4. Permissions: Repositories sekmesinde Add permissions, Contents, erişimi Read and write yap. Account sekmesine bir şey ekleme.
  5. Generate token deyip çıkan anahtarı kopyala, buraya yapıştır.

Anahtar sadece bu cihazda saklanır. Kimseyle paylaşma, sohbete de yazma.

Diğer cihazda Düzen'i aç, Ayarlar'da "QR ile anahtar al" de ve bunu okut. 60 saniye sonra kaybolur; kimseye gösterme.
